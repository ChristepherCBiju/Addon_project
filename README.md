# Addon_project

This repository contains my work from a five-day addon course at my college, covering Python from basic to advanced concepts.

## Contents

### addon5(classificaton_model).ipynb
This notebook explores several machine learning algorithms using Python and the scikit-learn library, with a primary focus on the Iris dataset. The methods demonstrated include:

- Convolutional Neural Networks (CNN)
- k-Nearest Neighbors (KNN)
- Linear Regression
- Polynomial Regression
- Logistic Regression
- Decision Trees

The notebook covers data loading, feature analysis, visualization, and practical implementation of these algorithms for classification and regression tasks.

### project5.ipynb
This notebook builds a decision tree classifier to predict Iris flower species. It covers:

- Loading and preprocessing the Iris dataset
- Training a decision tree model
- Saving the trained model using joblib
- Creating a FastAPI application (`main.py`) to serve predictions through a REST API
- Deployment steps using ngrok for public accessibility

The API allows users to send flower measurements and receive a predicted species in response.

---

This project is a practical demonstration of machine learning techniques and API development, reflecting topics covered in the college addon course, from data analysis and model training to deploying and exposing models for real-world usage.
